# Frequency Processing of the Image: Fourier Transform

Проект показывает, как работает частотная обработка изображения через преобразование Фурье. Скрипт читает изображение в оттенках серого, переводит его в частотную область, применяет набор низкочастотных и высокочастотных фильтров, а затем сохраняет результаты для сравнения.

## Что делает код

Основной файл проекта: [main.py](/Users/mirant/PycharmProjects/coi3/main.py)

Логика работы такая:

1. Загружается исходное изображение `image.jpg` в градациях серого.
2. Для изображения вычисляется двумерное БПФ (`np.fft.fft2`).
3. Нулевая частота переносится в центр спектра (`np.fft.fftshift`).
4. Строится матрица расстояний `D` от центра спектра до каждой точки.
5. На основе `D` создаются частотные маски:
   - ideal low pass
   - butterworth low pass
   - gaussian low pass
   - ideal high pass
   - butterworth high pass
   - gaussian high pass
6. Каждая маска умножается на спектр изображения.
7. Выполняется обратное преобразование Фурье, чтобы получить восстановленное изображение после фильтрации.
8. Скрипт сохраняет:
   - само ядро фильтра;
   - отфильтрованный спектр;
   - восстановленное изображение;
   - 3D-график поверхности фильтра.

## Как устроен код

### Константы

В начале файла задаются основные параметры:

- `IMAGE_PATH` - путь к исходному изображению;
- `D0_VALUES` - список радиусов отсечения;
- `D0_PAIRS` - пары значений `D0`, которые выводятся на сравнительных графиках;
- `BUTTERWORTH_N` - порядок фильтра Баттерворта;
- `SAVE_FOLDER` - папка для результатов.

### Вспомогательные функции

#### `to_uint8_image(img)`

Нормализует массив значений к диапазону `0..255` и переводит его в `uint8`. Это нужно для сохранения изображений на диск.

#### `create_spectrum_image(fshift)`

Строит визуализацию амплитудного спектра. Используется логарифм:

```python
20 * np.log(np.abs(fshift) + 1)
```

Это делает слабые частоты видимыми на изображении.

#### `create_distance_matrix(rows, cols)`

Создает матрицу расстояний от центра спектра до каждой точки. Эта матрица нужна, чтобы строить фильтры по радиусу `D0`.

## Фильтры

В коде реализованы 6 функций фильтрации.

### Низкочастотные

- `create_ideal_low_pass_filter(D, D0)`  
  Пропускает только частоты внутри радиуса `D0`.

- `create_butterworth_low_pass_filter(D, D0, n=2)`  
  Плавный низкочастотный фильтр без резкой границы.

- `create_gaussian_low_pass_filter(D, D0)`  
  Еще более плавный фильтр на основе гауссовой функции.

### Высокочастотные

- `create_ideal_high_pass_filter(D, D0)`  
  Удаляет низкие частоты внутри радиуса `D0`.

- `create_butterworth_high_pass_filter(D, D0, n=2)`  
  Плавный высокочастотный фильтр Баттерворта.

- `create_gaussian_high_pass_filter(D, D0)`  
  Гауссов высокочастотный фильтр с плавным подавлением низких частот.

## Как применяется фильтр

Функция `apply_frequency_filter(fshift, H)` делает три действия:

1. Умножает спектр `fshift` на маску `H`;
2. Делает обратный сдвиг спектра `ifftshift`;
3. Выполняет обратное БПФ `ifft2` и получает итоговое изображение.

Возвращаются:

- `filtered_shift` - спектр после фильтрации;
- `filtered_img` - изображение после обратного преобразования.

## Как формируются итоговые изображения

### `save_combined_filter_results(...)`

Создает таблицу из 3 колонок для каждого значения `D0`:

- `Kernel` - маска фильтра;
- `Filtered spectrum` - спектр после фильтрации;
- `Restored` - восстановленное изображение.

Это позволяет сразу видеть, как форма фильтра влияет на итоговую картинку.

### `save_combined_3d_filters(...)`

Строит 3D-поверхности фильтров для пары значений `D0`. Это удобно для визуального сравнения:

- у ideal-фильтра граница резкая;
- у butterworth-переход плавный;
- у gaussian-переход самый мягкий.

## Главный цикл программы

В конце файла находится основной цикл:

```python
for frequency_folder, filter_name, filter_func in filters:
```

Он проходит по всем фильтрам, создает для каждого отдельную папку и сохраняет:

- сравнительное изображение результатов;
- 3D-визуализацию фильтра.

То есть программа не просто применяет один фильтр, а автоматически генерирует полный набор материалов для анализа.

После запуска появляются такие файлы и папки:

```text

  low_frequency/
  high_frequency/

```

Внутри `results/low_frequency/` и `results/high_frequency/` сохраняются:

- `*_results.png` - таблицы с ядром, спектром и восстановленным изображением;
- `*_3d.png` - трехмерные графики фильтров.

## Краткий вывод по проекту

Этот код нужен для демонстрации того, как разные частотные фильтры влияют на изображение:

- низкочастотные фильтры сглаживают изображение и убирают детали;
- высокочастотные фильтры подчеркивают границы и мелкие структуры;
- значение `D0` меняет силу фильтрации;
- тип фильтра меняет резкость перехода в частотной области.
